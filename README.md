# Lumbar foraminal stenosis research

Exploratory source-only lumbar MRI ordinal grading research. Nested evaluation completed five patient-separated outer folds and 30 training stages. Previous model development used the same cohort, so this is not confirmatory external validation or clinical software.

This public repository contains research code and aggregate deliverables only. MRI, patient/target-level records, model checkpoints, credentials, and original dataset files must not be uploaded. Dataset access and licenses remain governed by the original resources.

Results: raw selected-procedure QWK 0.354 (95% CI 0.338–0.371), severe AP 0.183 (0.162–0.208), severe AUROC 0.847 (0.834–0.859). Higher QWK than baseline coexists with lower severe sensitivity. Calibration does not consistently improve probability accuracy. Independent external testing and author review remain outstanding.

A versioned aggregate analysis package is being prepared. This is a working research record, not a clinical product or final submitted manuscript.
